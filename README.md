# Technical Communication & Design

Sean Ryan’s selected earlier work in visual instruction, technical documentation, CAD, and fabrication.

Standalone static portfolio site. Open `index.html` using any local static server, or publish the repository root with GitHub Pages (main branch).

## Files and editing

- `index.html`: page content, styles, and interactive photo/PDF previews.
- `assets/`: optimized project photographs and model images.
- `guides/`: downloadable PDFs and preview pages.

All assets are local to this repository. No build step or external dependencies are required.

## Document editions

Equipment guides were created in 2023 and copyedited in 2026. Layouts, screenshots, and credits are retained. They are historical documentation; equipment procedures have not been updated or revalidated.

The 2023 Dice Vault team report is a public edition. Preliminary notes and grading sheets were omitted, and personal email addresses and telephone numbers were removed. Team credits and contributions remain. Original printed page numbers are retained.

Project and document credits appear on the page and in the PDFs. No blanket license is granted for third-party materials.
